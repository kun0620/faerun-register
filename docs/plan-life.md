# แผน: ชีวิตที่เล่นแล้วไม่จำเจ

## ปัญหาที่วัดได้ก่อนเริ่ม

วัดจากคนธรรมดา 820 ชีวิตที่ตอบเฉพาะคำถามที่เด้งขึ้นมา โดยไม่เปิดแผงใช้เงินและไม่เปลี่ยนจุดเน้นเอง (`idle.js`)

- **ชีวิตทำงานเงียบ:** ทำงาน 49 ปี มีเรื่องเกี่ยวกับอาชีพเกิดขึ้นแค่ 6.6 ปี ช่วงที่เงียบนานที่สุดคือ 21 ปี
- **ติดเงื่อนไขโดยไม่มีทางแก้:** 56% ของชีวิตจบลงตอนผลงานเต็มแล้วแต่ยังขาดเงื่อนไข ที่เจอบ่อยคือเครื่องมือช่าง, สเตตัส, สายสัมพันธ์ และทอง
- **มองไม่เห็นความคืบหน้า:** ผลงานขึ้นอย่างเงียบ ๆ

ต้นเหตุมีสามอย่าง: เหตุการณ์ไม่ต่อเนื่องกัน, ทุกช่วงของชีวิตให้ความรู้สึกเหมือนกัน และไม่มีเป้าหมายระยะสั้น

## ระบบทั้งหมด

1. **ชีวิตแบ่งเป็นบท** — วัยเด็ก → ฝึกงาน (5 ปีแรกในเส้นทาง: ปีละ 3 เรื่อง) → ตั้งตัว (ปีที่ 5–10: ปีละ 2 เรื่อง) → รุ่งเรือง → บั้นปลาย (ปีละ 1 เรื่องทุก 2–3 ปี)
2. **ตัวละครที่วนกลับมา** — อาจารย์และคู่แข่งมีชื่อและอยู่ไปตลอดเส้นทาง อาจารย์แก่ลง ป่วย และจากไป ส่วนคู่แข่งเลื่อนขั้นตามเส้นทางของตัวเอง ในอนาคตจะเพิ่มเพื่อนสนิทกับผู้อุปถัมภ์
3. **เรื่องที่ต่อกันหลายปี** — เรื่องละ 3–4 ตอน เช่น งานชิ้นใหญ่ หรือข่าวลือ
4. **เหตุการณ์ทั้งแคว้น** — สงคราม โรคระบาด หรือเทศกาล เกิดทุก 8–15 ปี กินเวลา 2–4 ปี และแต่ละสายได้รับผลไม่เหมือนกัน
5. **เป้าหมายระยะสั้น** — ทุก 5–8 ปีให้เลือกหนึ่งเป้าจากสามตัวเลือก
6. **ไม่ให้เหตุการณ์ซ้ำ** — เหตุการณ์ที่เคยเกิดแล้วจะไม่เกิดอีก ยกเว้นเหตุการณ์ที่ตั้งใจให้เกิดซ้ำได้ซึ่งต้องเว้น 10 ปี เหตุการณ์ถูกเลือกตามสถานะของตัวละคร และมีเรื่องหายาก 1–2% ต่อปี
7. **งานกับครอบครัว** — มีจังหวะที่ต้องเลือกระหว่างสองอย่างนี้
8. **ติดเงื่อนไขแล้วมีทางแก้** — ผู้ใหญ่ยังฝึกสเตตัสได้ และการ์ดแสดงความคืบหน้าทุกปี

ภาระในการเล่น: ปีหนึ่งให้เลือกเองได้ไม่เกิน 1 เรื่อง เรื่องที่เหลือเกิดขึ้นเองและทอยให้ดู หน้าต่างที่เด้งต้องไม่เกิน 2 ต่อนาที

## ลำดับการทำ

1. **รากฐาน** — เหตุการณ์งานที่เกิดเองและที่ถามให้เลือก, อาจารย์และคู่แข่ง, ทางแก้เงื่อนไข, การฝึกในวัยผู้ใหญ่, ความคืบหน้า ✓
2. **เนื้อหา** — เพิ่มเหตุการณ์ของแต่ละสาย และเรื่องที่ต่อกันหลายปี 6–8 เรื่อง
3. **ภาพใหญ่** — เหตุการณ์ทั้งแคว้น, เป้าหมายระยะสั้น, เพื่อนสนิทและผู้อุปถัมภ์
4. **บั้นปลาย** — รับศิษย์, ส่งต่อกิจการ, มรดก
5. **ปรับสมดุล**

## ชุดที่ 1 — สิ่งที่ลงมือแล้ว

- `PW` เก็บคำเฉพาะของแต่ละสาย (สถานที่ทำงาน หัวหน้า งาน ครู สภา ทักษะ) ให้เหตุการณ์กลางใช้ร่วมกันได้ทุกสาย
- `WAUTO` เหตุการณ์งานที่เกิดเองและทอยให้ดู ได้ผลเป็นผลงาน ทอง หรือสายสัมพันธ์กับอาจารย์และคู่แข่ง จำนวนต่อปีขึ้นกับช่วงของชีวิตทำงาน (`workPhase`) ตามที่วางไว้
- `WASK` คำถามจากงานที่ใช้ช่องคำถามประจำปี ได้แก่ งานชิ้นใหญ่, คู่แข่งโกง, บททดสอบจากอาจารย์, มีคนมาซื้อตัว, หนี้, งานกับบ้าน, คู่แข่งเลื่อนขั้นก่อน, การเมืองในสภา, เด็กมาขอเป็นศิษย์ และอาจารย์ล้มป่วย
- `S.cast` เก็บอาจารย์และคู่แข่ง ถ้าตอนอาจารย์ตายสายสัมพันธ์ถึง 65 จะได้ผลงาน +15 (สายช่างได้ชุดเครื่องมือด้วย)
- `fixDec` เมื่อผลงานเต็มแต่ยังขาดเงื่อนไข จะถามว่าจะแก้อย่างไร ถามหนึ่งครั้งต่อหนึ่งเงื่อนไข แล้วถามซ้ำได้ทุก 6 ปีมนุษย์
- การฝึกในวัยผู้ใหญ่ (`trainAdult`) ทำได้สองทาง คือผ่านคำถามทางแก้ หรือเลือกจุดเน้น "ฝึกฝนตัวเอง" ทอย d20 + ตัวปรับ เทียบ DC เท่ากับค่าสเตตัสปัจจุบัน ได้อีกไม่เกิน +2 และขึ้นได้ไม่เกิน 15 เพราะค่า 16 ที่ขั้นสูงสุดต้องการต้องมีมาแต่กำเนิด
- การ์ดขั้นต่อไปบอกผลงานที่ได้เมื่อปีที่แล้ว, เวลาโดยประมาณที่จะได้สอบ และชื่ออาจารย์กับคู่แข่ง แถบบนแสดงผลงาน และมีข้อความลอยเมื่อผลงานถึง 50 และ 100

### ปรับเพื่อรักษาสมดุล

- สอบขั้น 5 ไม่ผ่าน ผลงานเริ่มนับใหม่จาก 0 แทนที่จะเหลือ 50 ส่วนผลงานจากเหตุการณ์งานตอนอยู่ขั้น 4 ได้ครึ่งเดียว
- `RANK_MUL` ลดจาก `[1,1,1.15,1.4,1.75,2.5]` เป็น `[1,1,1.1,1.25,1.45,2.2]` เพราะตอนนี้คนไปถึงขั้นสูงได้มากขึ้น
- ช่องว่างระหว่างหน้าต่างในวัยผู้ใหญ่ ×1.22 เพราะปีทำงานมีเหตุการณ์ที่เกิดเองเติมให้อยู่แล้ว วัยเด็กคงเดิม เพราะถ้าลดช่องคำถามในวัยเด็ก คนจะได้เลือกเทพน้อยลง
- เงินกู้จากสมาคมให้เฉพาะสายผืนดินที่ต้องซื้อที่จริง ทองที่เงื่อนไขขอให้ "มีไว้" ต้องหามาเอง

## ชุดที่ 2 — สิ่งที่ลงมือแล้ว

- **เรื่องต่อเนื่อง** (`ARCS`) — เริ่มที่งาน แล้วกลับมาทุก 1–3 ปีมนุษย์ เรื่องละ 3–4 ตอน แต่ละตอนขึ้นกับสิ่งที่เลือกไว้ก่อนหน้า (`a.f`) ตอนหนึ่งจะถามในช่องคำถามประจำปี หรือทอยเองให้ดูก็ได้ มีได้พร้อมกันไม่เกิน 2 เรื่อง และเรื่องเดิมจะไม่เกิดซ้ำในเส้นทางเดียวกัน
  - **งานชิ้นใหญ่ที่สุดในชีวิต** — รับงาน → วัตถุดิบขาด → ใกล้กำหนดส่ง (อดนอน / ขอเลื่อน / จ้างคู่แข่ง) → ส่งงาน DC 15 ลดหรือเพิ่มตามทางที่เลือกไว้
  - **ข่าวลือ** — ข่าวแพร่ → สืบหา / ปล่อยข่าวกลับ / ทำงานเงียบ ๆ → ถ้าคู่แข่งไม่ชอบคุณ คนปล่อยข่าวคือคู่แข่ง
  - **ศึกกับคู่แข่ง** (ใจคู่แข่งต่ำกว่า 35) — คู่แข่งท้า → ถูกลอบทำลายงาน → คู่แข่งล้ม จะช่วยให้กลายเป็นมิตร หรือปล่อยให้ย้ายออกจากเมือง
  - **ศิษย์** (รับศิษย์แล้ว) — ศิษย์ทำงานพัง → ศิษย์จะไป → ศิษย์ฝีมือขึ้น หรือไปเปิดกิจการเอง
  - **หุ้นส่วน** (ผืนดิน ช่าง การค้า) — ลงขัน → ปีแรก → ขยายกิจการหรือถอนทุน → รวย หรือหุ้นส่วนหอบเงินหนี
  - **งานสุดท้ายของอาจารย์** — รับปาก → ทำต่อ → ชื่อทั้งสองคนสลักไว้ด้วยกัน
  - **วิกฤตประจำสาย** — ปีแล้ง / ของปลอม / ด่านภาษี / โรคระบาด / ตำราต้องห้าม / ศึกชายแดน
- เพิ่มเหตุการณ์ของแต่ละสายอีกสายละ 2 เรื่อง
- จุดเน้น "ทุ่มให้อาชีพ" ทำให้ทอยเหตุการณ์งานได้เปรียบ (ไม่รวมทอยป้องกัน) จุดเน้นจึงเปลี่ยนสิ่งที่เกิดขึ้นที่งานได้จริง
- ผลงานจากเหตุการณ์และคำถามทุกชนิดผ่าน `workMerit` ซึ่งลดลงตามขั้น (ขั้น 3 ×0.7 · ขั้น 4 ×0.4) ส่วนสอบขั้น 5 ใช้ DC 26
- ในวัยผู้ใหญ่ช่องว่างระหว่างหน้าต่างเป็น ×1.5 เพราะตอนนี้เกือบทุกช่องมีเรื่องให้ถาม จำนวนหน้าต่างต่อนาทีเลยแปรตามความกว้างของช่องโดยตรง ส่วนคำถามงานที่ไม่ได้มาจากเรื่องต่อเนื่องลดเหลือ .18 / .13 / .08 ตามช่วงของชีวิตทำงาน
