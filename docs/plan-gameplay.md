# แผนเกมเพลย์: จากดูชีวิตเป็นเล่นชีวิต

ต่อจาก `docs/plan-dnd-rework.md` ที่ทำครบแล้ว · ไฟล์ที่แก้: `index.html` · ตัววัด: `tools/agency.js`

## Context

การรื้อเป็น D&D ทำให้ลูกเต๋ามองเห็นได้ แต่ยังไม่ทำให้ผู้เล่นได้เล่น วัดจากชีวิตมนุษย์ 1,500 ชีวิต (ความยาวชีวิต 12 นาที):

| | ตอนนี้ |
|---|---|
| การตัดสินใจที่ผู้เล่นได้เลือกต่อชีวิต | 9 ครั้ง (หนึ่งครั้งทุก 80 วินาที) |
| ช่วงที่นานที่สุดที่ไม่มีอะไรให้เลือก | 23 ปี ≈ 4 นาทีจริง |
| การทอยต่อชีวิต | 101 ครั้ง ผู้เล่นไม่ได้เลือกอะไรเลยในการทอยเหล่านี้ |
| คำถามประจำที่เจอแทบทุกชีวิต | เพื่อนคนแรก วิหาร งานอดิเรก อาชีพ แต่งงาน สัตว์เลี้ยง เทพ (80–97%) |

หัวใจของ D&D คือผู้เล่นบอกว่าจะทำอะไร แล้วลูกเต๋าค่อยตัดสินผล ตอนนี้เกมข้ามครึ่งแรกไปทั้งหมด

ข้อที่ต้องเช็กก่อนลงมือ: ในการจำลองไม่มีจุดตัดสินใจ "เสียงเรียก" (`call`) ขึ้นเลยสักครั้ง อาจเป็นบั๊ก หรือถูกเปลี่ยนชื่อไปตอนรื้อ D&D

## หลักการ

1. ทุกการทอยที่มีน้ำหนักต้องมีการตัดสินใจของผู้เล่นมาก่อน
2. ห้ามเด้งหน้าต่างถี่จนน่ารำคาญ เรื่องเล็กใช้ "ท่าทีประจำตัว" ที่ผู้เล่นตั้งไว้ จะเปิดหน้าต่างถามเฉพาะเรื่องใหญ่
3. ความถี่ของการตัดสินใจคิดต่อนาทีจริง ไม่ใช่ต่อปีในเกม ทุกเผ่าจึงได้เลือกถี่เท่ากัน
4. ตัวเลขสมดุลเดิมใน `docs/plan-dnd-rework.md` ต้องยังเข้าเป้าเหมือนเดิม

---

## ก. เลือกวิธีรับมือก่อนทอย

**ตารางภัยรายปีมีทางรับมือ** ภัยแต่ละแบบในทอยป้องกันประจำปี (`annualSave`) ได้ทางรับมือ 3–4 ทาง แต่ละทางใช้สเตตัส ความชำนาญ และผลข้างเคียงต่างกัน ตัวอย่าง ปีข้าวแล้ง:
- ทำงานหนักขึ้น — STR + กีฬา · ไม่ผ่านแล้วอ่อนล้า
- ออกหาของป่า — WIS + เอาตัวรอด · ไม่ผ่านแล้วเสียเลือด
- ขอยืมญาติ — CHA + โน้มน้าว · สายสัมพันธ์ลด ไม่ว่าผ่านหรือไม่
- ขโมยจากยุ้งฉางเจ้าเมือง — DEX + ลอบเร้น · alignment ไปทางเสรีและร้าย ไม่ผ่านแล้วโดนจับ

**ท่าทีประจำตัว** เป็นตัวตั้งค่าบนแผงหลัก (ขยันสู้ / หัวไวเอาตัวรอด / พึ่งคนรอบตัว / ทำทุกทางที่รอด) ปีที่มีเรื่องเล็กจะใช้ทางรับมือตามท่าทีนี้โดยไม่ถาม แล้วบันทึกว่าใช้ทางไหน

**เรื่องใหญ่ถามทุกครั้ง** ภัยถึงชีวิต (`runThreat`) และราวหนึ่งในหกของปีที่มีภัย (คิดเทียบปีมนุษย์) จะเปิดหน้าต่างให้เลือกทางรับมือ แต่ละทางโชว์ DC, โบนัสของตัวละคร และโอกาสผ่านเป็นเปอร์เซ็นต์ ผู้เล่นจะเห็นทันทีว่าสเตตัสของตัวเองมีผลอย่างไร

**โหมดอัตโนมัติ** เลือกทางรับมือที่โอกาสผ่านสูงสุดภายใต้ท่าทีประจำตัว และ Ideal ในข้อ ข.

## ข. Ideal / Bond / Flaw และ Inspiration

**เลือกตอนได้ background** เกมเสนอ Ideal 3 ข้อ Flaw 3 ข้อตาม background (ตามตาราง 5e) ส่วน Bond มาจากชีวิตจริงที่ผ่านมา เช่น เพื่อนคนแรก แม่ บ้านเกิด หรือเทพประจำตัว

**ทางรับมือและตัวเลือกติดป้าย** ตัวเลือกที่ตรงกับ Ideal, Bond หรือ Flaw จะมีป้ายบอก เลือกตาม Ideal หรือ Bond ได้ Inspiration เลือกตาม Flaw ก็ได้ Inspiration เหมือนกัน แต่มีราคาที่ต้องจ่าย เก็บ Inspiration ได้ครั้งละ 1 ตามกฎ 5e

**ใช้ Inspiration** กดใช้ได้ในหน้าต่างเรื่องใหญ่ และตอนทอย death save เพื่อได้ advantage

**Bond มีชีวิต** ถ้าคนที่ผูกพันตาย ย้ายไป หรือห่างเหินกัน จะเกิดเหตุการณ์ใหญ่ ทำอะไรเพื่อเขาได้ advantage

**การตัดสินของเคเลมวอร์เพิ่มหนึ่งบรรทัด** "อยู่ตามอุดมการณ์ X ครั้ง ทิ้งอุดมการณ์ Y ครั้ง" และหน้าจอตายโชว์ Ideal Bond Flaw ของชีวิตนั้น

## ค. คำถามตามสภาพชีวิต

**เงื่อนไขจากสถานะ** เพิ่มฟิลด์ `when` ให้ `DECS` อ่านจากสถานะจริง เช่น หนี้ โรคเรื้อรัง อายุลูก แคว้น เผ่าที่ถูกรังเกียจ alignment สุดขั้ว ศรัทธา ความอ่อนล้า ความมั่งคั่ง เพื่อนหรือคนที่เกิดพร้อมกันตาย

**คลังใหญ่ขึ้น ซ้ำน้อยลง** เป้าหมายคือมีจุดตัดสินใจรวมอย่างน้อย 60 จุด แบ่งเป็นตระกูล แต่ละตระกูลขึ้นได้จำกัดต่อชีวิต และถ่วงน้ำหนักให้ตัวที่เพิ่งเจอในชีวิตก่อน (เก็บใน localStorage) ขึ้นยากขึ้น

**ความถี่เท่ากันทุกเผ่า** โอกาสเกิดคำถามต่อปีคูณด้วย `yearScale()` ส่วนเผ่าอายุยืนได้คำถามเฉพาะเผ่า เช่น เอลฟ์ที่ดูเพื่อนมนุษย์แก่และตายไปทีละคน หรือคนแคระกับความแค้นของตระกูล

**ลดคำถามประจำ** เพื่อนคนแรก สัตว์เลี้ยง และงานอดิเรก ให้เป็นหนึ่งในหลายทางที่อาจเกิด ไม่ใช่เกิดแทบทุกชีวิต ส่วนเทพกับ background ยังเป็นแกนกลางที่ทุกชีวิตต้องผ่าน

## ง. เผชิญหน้าแบบเลือกทาง

ก่อนการเผชิญหน้า (`encounter`) โชว์ศัตรูแบบย่อ (ชื่อ AC เลือด ระดับความยากตามเลเวล) แล้วให้เลือกทาง:
- **สู้** — ทอยโจมตี vs AC แล้วทอยความเสียหาย · ได้ XP และของเต็ม
- **หนี** — DEX + กายกรรมหรือลอบเร้น vs สังเกตของศัตรู · ได้ XP น้อย ไม่ผ่านแล้วโดนตี
- **เจรจาหรือข่มขู่** — CHA + โน้มน้าวหรือข่มขู่ · ได้ XP ครึ่งหนึ่ง ปลอดภัยกว่า และขยับ alignment
- **ใช้เวท** — เฉพาะ class ที่ร่ายเวทได้ · ใช้ความสามารถหลักของ class

## ลำดับงาน

1. เช็กและแก้เรื่อง `call` ที่ไม่ขึ้น
2. ข้อ ก. ทางรับมือ และท่าทีประจำตัว เพราะเป็นโครงที่ข้อ ข. และ ง. ใช้ต่อ
3. ข้อ ข. Ideal / Bond / Flaw และ Inspiration
4. ข้อ ง. เผชิญหน้าแบบเลือกทาง
5. ข้อ ค. คลังคำถาม เป็นงานเขียนเนื้อหาภาษาไทยที่ใหญ่ที่สุด แบ่งให้คนอื่นช่วยเขียนได้ เช่น AIPASS
6. รัน `tools/agency.js` กับ `tools/sim.js` จนเข้าเป้าทั้งสองชุด

## ความเสี่ยง

- **หน้าต่างเด้งถี่จนน่ารำคาญ** เป็นความเสี่ยงอันดับหนึ่ง จึงต้องวัด "หน้าต่างต่อนาที" ด้วย ไม่ใช่วัดแค่จำนวนการตัดสินใจ
- **ทางรับมือทำให้สมดุลเพี้ยน** เพราะผู้เล่นจะเลือกทางที่สเตตัสตัวเองสูงที่สุด อัตราผ่านจึงสูงขึ้นกว่าตอนทอยอัตโนมัติ ต้องปรับ DC ใหม่
- **เนื้อหาภาษาไทยปริมาณมาก** คำถามอย่างน้อย 60 จุดพร้อมตัวเลือก เป็นงานเขียนมากกว่างานโค้ด
