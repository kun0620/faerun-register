# ทะเบียนวิญญาณแห่งแฟรูน

เกมจำลองชีวิตในโลก Forgotten Realms สุ่มให้เกิดตามสัดส่วนประชากรของเผ่า แคว้น ชนชั้น และยุค
แล้วใช้ชีวิตนั้นไปจนสุดทาง — ครั้งเดียว ได้แรงบันดาลใจจากเกม 1in8b.life

## เล่น

เปิด `index.html` ในเบราว์เซอร์ได้เลย ทั้งเกมอยู่ในไฟล์เดียว ไม่ต้อง build

## โครงสร้าง

- `index.html` — ตัวเกมทั้งหมด (HTML + CSS + JS)
- `docs/plan-dnd-rework.md` — แผนรื้อให้เดินด้วยกฎ D&D 5e (ลงมือครบทั้งสามชุดแล้ว)
- `tools/` — ตัวทดสอบ headless ไม่ต้องติดตั้งอะไรนอกจาก node
  - `node tools/sim.js 3000` — จำลอง 3,000 ชีวิต รายงานตัวเลขเทียบตาราง "เป้าหมายตัวเลข"
  - `node tools/dicetest.js` — ทอย `check()` 100,000 ครั้ง ยืนยัน d20 เรียบ และ advantage/disadvantage ถูกทาง
  - `node tools/browser.js` — เปิดในเบราว์เซอร์จริง (ต้องมี playwright) วาด portrait/ฉากทุกเผ่า และเช็กว่าจอไม่ล้นแนวนอน

## สถานะ

เวอร์ชัน 7 — ทุกผลลัพธ์ที่สำคัญมาจาก d20 ที่ผู้เล่นเห็น: ทอยป้องกันประจำปี, ภัยถึงชีวิต → เลือดหมด → คนในบ้านทอย Medicine → death saves → การตัดสินของเคเลมวอร์
ก่อนเผยแพร่ทุกครั้งให้รัน `tools/sim.js` ยืนยันตัวเลขตามตาราง "เป้าหมายตัวเลข" ในแผน
