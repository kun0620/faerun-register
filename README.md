# ทะเบียนวิญญาณแห่งแฟรูน

เกมจำลองชีวิตในโลก Forgotten Realms สุ่มให้เกิดตามสัดส่วนประชากรของเผ่า แคว้น ชนชั้น และยุค
แล้วใช้ชีวิตนั้นไปจนสุดทาง — ครั้งเดียว ได้แรงบันดาลใจจากเกม 1in8b.life

## เล่น

เปิด `index.html` ในเบราว์เซอร์ได้เลย ทั้งเกมอยู่ในไฟล์เดียว ไม่ต้อง build

## โครงสร้าง

- `index.html` — ตัวเกมทั้งหมด (HTML + CSS + JS)
- `docs/plan-dnd-rework.md` — แผนรื้อให้เดินด้วยกฎ D&D 5e ที่อนุมัติแล้ว ยังไม่ได้ลงมือ

## สถานะ

ตอนนี้คือเวอร์ชัน 6 ย้ายมาจาก Claude artifact งานถัดไปอยู่ในแผนข้างบน
ก่อนเผยแพร่ทุกครั้งให้รันการจำลองหลายพันชีวิตยืนยันตัวเลขตามตาราง "เป้าหมายตัวเลข" ในแผน
