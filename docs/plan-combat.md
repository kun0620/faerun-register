# แผน: การต่อสู้ที่ได้ลุ้นทีละยก

## ปัญหาตอนนี้

การต่อสู้ตอนนี้จบในการเลือกครั้งเดียว (`encSit` / `encOutcome`): เลือกว่าจะสู้ หนี เจรจา หรือร่ายเวท แล้วทอยโจมตีหนึ่งครั้งกับทอยป้องกันหนึ่งครั้ง โจมตีโดนครั้งเดียวก็ชนะเลย ผลที่ตามมาคือ

- เลือดของศัตรูบนการ์ดไม่มีผลกับการต่อสู้
- AC จากเกราะแทบไม่ได้ใช้ เพราะศัตรูไม่ได้ทอยโจมตีใส่เรา มีแค่ให้เราทอยป้องกัน
- แต่ละคลาสสู้เหมือนกันหมด มีแค่สายเวทที่เปลี่ยนจากฟันเป็นร่ายเวท
- เพื่อนร่วมทาง ยารักษา และตะเกียงไม่มีบทบาทในการต่อสู้
- คนธรรมดาที่โดนโจรดักหรือเจอสัตว์ร้าย ได้แค่ทอยรับมือเหมือนตอนป่วยหรือหนาว

## สิ่งที่ตกลงกันแล้ว

1. คนธรรมดาก็ต้องสู้ และต้องมีทางเลือกให้ลุ้น ไม่ใช่มีแค่ยอมแพ้
2. สู้กัน 3 ยก ถ้ายังไม่จบ ท่าทีประจำตัวจะสู้ต่อให้จนจบ
3. บอสมี 2 ช่วง พอเลือดเหลือครึ่งหนึ่งจะเปลี่ยนท่า

## กติกา

### หนึ่งการต่อสู้ = หนึ่งหน้าต่าง
ทั้งการต่อสู้อยู่ในหน้าต่างเดียว หน้าต่างนี้แสดงหลอดเลือดของทุกฝ่าย, AC, ยกที่เท่าไร, สรุปว่ายกที่แล้วเกิดอะไรขึ้น และทางเลือกพร้อมโอกาสสำเร็จเป็นเปอร์เซ็นต์ เลือกหนึ่งทางแล้วหน้าต่างไม่ปิด แต่จะเดินยกต่อไปในหน้าต่างเดิม กด "ให้ท่าทีสู้ต่อจนจบ" ได้ทุกเมื่อ

การต่อสู้ที่ไม่ได้เปิดหน้าต่าง (เรื่องเล็กที่ท่าทีตัดสินให้) ก็คิดตามกติกาเดียวกันทุกยก แล้วสรุปเป็นบรรทัดเดียวในบันทึกชีวิต เช่น `ปะทะหมาป่าสามตัว — ชนะใน 3 ยก · เสียเลือด 7 · ธอรินบาดเจ็บ`

### ลำดับในหนึ่งยก
คุณลงมือ → เพื่อนร่วมทาง (ลงมือเอง) → ศัตรู

ถ้าโดนซุ่มโจมตี ยกแรกศัตรูได้ลงมือก่อน ยกเว้นทอยการรับรู้ผ่าน

### ศัตรู
- ใช้เลือดตามการ์ด (`FOES`) และเพิ่มค่าโจมตีกับความเสียหายตามระดับ:

  | ระดับ | โจมตี | ความเสียหาย |
  |---|---|---|
  | 1 | +4 | 1d6+2 |
  | 3 | +5 | 1d8+3 |
  | 5 | +6 | 2d8+4 |
  | 9 | +8 | 3d10+5 |

- ศัตรูที่มาเป็นฝูง (ก็อบลิน หมาป่า โคบอลด์ ออร์ค) แยกเป็น 2–3 ตัว แบ่งเลือดกัน
- ท่าพิเศษของศัตรู (`hz`) จะออกทุก 2 ยก เป็นทอยป้องกัน เช่น พิษ ลมหายใจมังกร หรือคำสาป

### ทางเลือกของผู้เล่น (นักผจญภัย)
| ทางเลือก | ผล |
|---|---|
| โจมตี | ทอยโจมตีใส่ AC ด้วยอาวุธที่ถืออยู่ |
| ท่าเด่นของคลาส | ดูตารางด้านล่าง ใช้ได้จำกัดต่อปี (ฟื้นทุกปี เทียบเท่าการพักยาว) |
| ร่ายเวท (สายเวท) | ใช้ช่องเวท: เลเวล 1 มี 2 ช่อง, เลเวล 5 มี 4 ช่อง, เลเวล 9 ขึ้นไปมี 6 ช่อง |
| ตั้งรับ | ศัตรูโจมตีคุณแบบเสียเปรียบหนึ่งยก |
| ใช้ของ | ยารักษา (ฟื้น 2d4+2), ยาต้านพิษ, ตะเกียง (หายจากเสียเปรียบตอนอยู่ในที่มืด) |
| เจรจา / ข่มขู่ | ทำได้แค่ยกแรก และใช้กับอันเดดไม่ได้ ไม่ผ่านแล้วศัตรูได้โจมตีฟรีหนึ่งครั้ง |
| ถอย | ทอย DEX แข่งกับศัตรู ไม่ผ่านแล้วโดนตีฟรี ถ้ามีเชือก ได้เปรียบตอนถอยขึ้นที่สูง |

### ท่าเด่นของแต่ละคลาส
| คลาส | ท่า | ผล |
|---|---|---|
| Fighter | ฮึดสู้ / โจมตีสองครั้ง | ฟื้น 1d10+เลเวล หรือโจมตี 2 ครั้งในยกเดียว |
| Barbarian | โกรธคลั่ง | ความเสียหายที่ได้รับลดครึ่งหนึ่ง และตีแรงขึ้น +2 อยู่ 3 ยก |
| Rogue | แทงลอบ | +1d6 ทุก 2 เลเวล ใช้ได้เมื่อมีเพื่อนประชิดศัตรู หรือคุณได้เปรียบ |
| Wizard | ลูกไฟ (เลเวล 5 ขึ้นไป) | 8d6 ใส่ศัตรูทุกตัว ศัตรูทอยป้องกัน DEX ผ่านโดนครึ่งเดียว |
| Cleric | รักษา | ฟื้น 1d8+WIS ให้ตัวเองหรือเพื่อน |
| Bard | ปลุกใจ | ทุกคนในฝ่ายคุณได้เปรียบหนึ่งยก |
| Ranger | ศัตรูคู่แค้น | +1d6 กับสัตว์ร้ายหรืออันเดด (เลือกไว้ตอนเป็นนักผจญภัย) |
| Druid | แปลงร่าง | ได้เลือดก้อนที่สอง (หมี: 34) จนกว่าก้อนนั้นจะหมด |

### บอส (ท้ายภารกิจ)
- พอเลือดบอสลดเหลือครึ่งหนึ่ง จะเข้าช่วงที่ 2 และหน้าต่างประกาศให้เห็น เช่น
  - มังกรบินขึ้นแล้วพ่นไฟใส่ทุกคน
  - ไลช์เรียกโครงกระดูกออกมาสองตัว
  - บีโฮลเดอร์เปิดตาลบล้างเวท (ร่ายเวทไม่ได้ 1 ยก)
  - โทรลล์ฟื้นเลือดทุกยก ยกเว้นยกที่โดนไฟ
- การต่อสู้กับบอสยาวได้ถึง 5 ยก ก่อนให้ท่าทีสู้ต่อจนจบ

### คนธรรมดาก็ต้องสู้ (โจร, สัตว์ร้าย, วิวาท)
คนธรรมดาเลือดราว 4 AC 10 อาวุธเป็นกระบองหรือมีดสั้นถ้ามี ทุกทางเลือกต้องมีอะไรให้ลุ้น:

| ทางเลือก | ผล |
|---|---|
| ยอมให้ของ | เสียทองครึ่งหนึ่ง แต่รอดแน่ |
| ตะโกนเรียกคนช่วย | ทอย CHA ถ้าอยู่ในหมู่บ้านและสายสัมพันธ์สูงจะได้เปรียบ ผ่านแล้วศัตรูหนี |
| ขว้างทรายใส่ตา | ทอย DEX ผ่านแล้วศัตรูโจมตีเสียเปรียบ 2 ยก |
| วิ่งหนี | ทอย DEX แข่งกับศัตรู ไม่ผ่านโดนตีฟรี |
| พุ่งชนสุดตัว | ทอย STR ยาก ผ่านแล้วศัตรูล้มหรือหนีไปเลย ไม่ผ่านโดนตีแรง |
| สู้ด้วยอาวุธ | ถ้ามีมีดสั้น ได้ +1 |
| (ถ้าชนะ) ค้นตัวโจร | อาจได้ถุงเงินของมัน |

ภาพที่ตั้งใจให้เห็นคือ คนธรรมดาสู้ได้และบางครั้งก็ชนะได้แบบน่าภูมิใจ แต่ทุกการตัดสินใจเสี่ยงชีวิตจริง

### สภาพสนาม (สุ่มหนึ่งอย่าง หรือไม่มีเลย)
| สภาพ | ผล |
|---|---|
| ซุ่มโจมตี | ยกแรกศัตรูได้ลงมือก่อน ยกเว้นทอยการรับรู้ผ่าน |
| มืด | เสียเปรียบตอนโจมตี ถ้าไม่มีตะเกียงหรือ darkvision |
| ทางแคบ | ศัตรูเข้ามาได้ทีละตัว |
| ที่สูง | ฝ่ายที่อยู่บนที่สูง +2 ตอนโจมตี |

## จำนวนหน้าต่าง
การต่อสู้หนึ่งครั้งนับเป็นหนึ่งหน้าต่าง และเปิดหน้าต่างเฉพาะเรื่องใหญ่ในสัดส่วนเท่าเดิม (`BIG_SHARE`) จำนวนหน้าต่างต่อนาทีจึงไม่ควรเปลี่ยน

## เป้าที่จะวัด
| ตัวชี้วัด | เป้า |
|---|---|
| จำนวนยกเฉลี่ยต่อการต่อสู้ปกติ | 2.5–3.5 |
| สัดส่วนนักผจญภัย / อายุกลางของนักผจญภัย | ~20% / ใกล้ 72 ปีเท่าเดิม |
| ครั้งที่ต้องทอยรักษาชีวิตต่อชีวิต | 1–2 เท่าเดิม |
| คนธรรมดาที่ได้สู้จริง | ไม่เกิน 0.5 ครั้งต่อชีวิต |
| คนธรรมดาที่ตายจากการสู้ | ไม่เกิน 3% ของชีวิต |
| ชนะบอส | 55–70% |
| หน้าต่างต่อนาที | ไม่เกิน 2 |

## ลำดับการทำ
1. ระบบต่อสู้ทีละยก และหน้าต่างการต่อสู้สำหรับการเผชิญหน้าของนักผจญภัย
2. ท่าเด่นของแต่ละคลาส, ช่องเวท และการใช้ของกลางการต่อสู้
3. ฉากในภารกิจ และบอสแบบ 2 ช่วง
4. การต่อสู้ของคนธรรมดา (แทนการรับมือโจรและสัตว์ร้ายแบบเดิม)
5. ปรับสมดุลตามตารางเป้า และทดลองเล่นในเบราว์เซอร์

## สิ่งที่ลงมือแล้ว

ทำครบทั้ง 4 ขั้นในรอบเดียว เพราะทั้งหมดใช้ระบบต่อสู้ตัวเดียวกัน (`newFight` / `fightRound` / `openFight` / `runFight`)

- **การเผชิญหน้าของนักผจญภัย** (`encounter`), **บอสท้ายภารกิจ** (`runQuest`) และ**โจรกับสัตว์ร้าย** (`runThreat`) สู้กันทีละยกแล้ว ลบ `encSit`, `encOutcome`, `bossSit` และรายการรับมือแบบเดิมสำหรับโจรกับสัตว์ร้ายออก
- **หน้าต่างการต่อสู้** — หลอดเลือดของศัตรู คุณ และเพื่อนร่วมทาง, AC, สภาพสนาม, สรุปยกที่แล้ว, ทางเลือกพร้อมโอกาสผ่านเป็นเปอร์เซ็นต์ และปุ่ม "ให้ท่าทีสู้ต่อจนจบ" พอครบ 3 ยก (บอส 5 ยก) ท่าทีจะสู้ต่อให้จนจบ แล้วขึ้นหน้าสรุปในหน้าต่างเดิม การต่อสู้ที่ไม่เปิดหน้าต่างใช้กติกาเดียวกัน แล้วสรุปเป็นบรรทัดเดียว
- **ท่าเด่นของแต่ละคลาส** (`FEAT`) ฟื้นทุกปีพร้อมช่องเวท (`SLOTS_BY`) ยารักษาดื่มได้กลางการต่อสู้ ยาต้านพิษให้ได้เปรียบตอนทอยป้องกันพิษ ตะเกียงหรือ darkvision แก้ความมืด และเชือกช่วยตอนถอย
- **บอสช่วงที่ 2** (`PHASE2`) — มังกรบินขึ้นแล้วพ่นไฟใส่ทุกคน (ระหว่างบิน อาวุธโจมตีเสียเปรียบ), ไลช์เรียกโครงกระดูก 2 ตัว, บีโฮลเดอร์ลบล้างเวท 1 ยก, โทรลล์ฟื้นเลือดยกละ 5 จนกว่าจะโดนเวท ส่วนบอสตัวอื่นคลั่งขึ้นเมื่อเลือดเหลือครึ่ง
- **คนธรรมดา** — ยอมให้ของ, ตะโกนเรียกคนช่วย, ขว้างทรายใส่ตา, พุ่งชนสุดตัว, ตีด้วยกระบองหรือมีด, ตั้งรับ หรือวิ่งหนี โจรต้องการเงินมากกว่าชีวิต ถ้าโดนตีจนล้มจะเหลือเลือด 1 และถูกปล้นเงินไป 60% (`subdue`) ส่วนสัตว์ร้ายเอาถึงตายได้จริง ถ้าชนะโจร มีโอกาสครึ่งหนึ่งที่จะได้ถุงเงิน และจิตใจ +4
- **ขวัญกำลังใจ** — ถ้าเลือดรวมของฝูงลดเหลือ 35% (ฝ่ายศัตรูของคนธรรมดาเหลือ 55%) ที่เหลือจะแตกหนี แต่บอสไม่หนี ฝ่ายท่าทีจะถอยเมื่อเลือดเหลือไม่ถึง 45% (ยกเว้นท่าทีขยันสู้) และถอยแน่เมื่อเหลือไม่ถึง 20% ถ้าไม่มียาให้ดื่ม
- **ตัวเลขของศัตรู** — การ์ดเขียนไว้สำหรับคณะ 4 คน จึงใช้เลือด ×0.6 (`FOE_HP`) ค่าโจมตีและความเสียหายตามระดับอยู่ใน `FOE_ATK` และท่าพิเศษของศัตรูออกทุก 2 ยก แรง ×1.25
- **เพื่อนร่วมทาง** ทอยโจมตีเองทุกยก ถ้าล้มลงระหว่างการต่อสู้ มีโอกาส 35% ที่จะไม่ได้กลับมา

## ตัวเลข

| ตัวชี้วัด | ค่าที่วัดได้ | เป้า |
|---|---|---|
| จำนวนยกเฉลี่ย | 2.2 | 2.5–3.5 |
| การเผชิญหน้าของนักผจญภัย | ชนะ 84% · ล้มลง 13% · หนี 3% | — |
| บอส | ชนะ 59% · ล้มลง 29% · ถอย 12% | ชนะ 55–70% |
| การต่อสู้ของคนธรรมดา | ชนะ 47% · ถูกปล้น 31% · ล้มลง 15% · หนี 6% | — |
| คนธรรมดาที่เคยสู้ / ตายเพราะการสู้ | 31% / 2.7% | — / ไม่เกิน 3% |
| นักผจญภัย / อายุกลาง | 21.3% / 71 | ~20% / ~72 |
| ครั้งที่ต้องทอยรักษาชีวิตต่อชีวิต / ตายเมื่อทอย | 1.59 / 65% | 1–2 / 60–70% |
| หน้าต่างต่อนาที | 1.95 | ไม่เกิน 2 |
| จ่ายค่าชุบชีวิตไหว / ไร้ศรัทธา | 12.6% / 35.0% | 8–12% / 25–35% |

การต่อสู้จบเร็วกว่าเป้า เพราะฝูงศัตรูแตกหนีเมื่อเลือดเหลือ 35% ถ้าลองลดเกณฑ์ลงเหลือ 25% การต่อสู้จะยาวขึ้นนิดเดียว แต่ล้มลงเพิ่มจาก 13% เป็น 19% จึงคงไว้ที่ 35% ส่วนบอสที่ล้มลงเกือบ 1 ใน 3 ควรดูอีกครั้งหลังจากได้เล่นจริง
