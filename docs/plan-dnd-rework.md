# รื้อ "ทะเบียนวิญญาณแห่งแฟรูน" ให้เดินด้วยกฎ D&D จริง

ไฟล์เดียว: `scratchpad/faerun-register.html` (1,705 บรรทัด) · เผยแพร่ที่ https://claude.ai/artifact/Bp9pCjjcHCpg2njCLsg8vY

## Context

เวอร์ชัน 6 ที่ใช้งานอยู่คือเกม 1in8b ที่ทาคำศัพท์ D&D ทับ ไม่ใช่เกม D&D

ปัญหาที่ชัดที่สุด: เกมทอย 4d6 ตัดลูกต่ำสุดให้ตั้งแต่เกิด แล้วแทบไม่ได้ใช้ค่าพวกนั้นเลย ถึงขั้นมีข้อความแก้ตัวอยู่ในเกมว่า "ชาวนาส่วนใหญ่ไม่เคยได้ใช้มัน" — ฟังดูเหมือนคำพูดเชิงธีม แต่จริง ๆ คือการยอมรับว่าไม่ได้สร้างระบบ นอกจากนี้ผู้เล่นไม่เคยเห็นลูกเต๋าสักลูก และความตายเป็นแค่ `Math.random() < hazard()` ที่ซ่อนอยู่

เป้าหมายคือให้ทุกผลลัพธ์สาวกลับไปถึงลูกเต๋าที่ผู้เล่นเห็นกับตา และเพื่อให้หน้าจอตอนตายส่งของจริงได้สองอย่าง: **character sheet เต็มใบที่ไม่เคยได้ใช้** กับ **การตัดสินของเคเลมวอร์ที่ Fugue Plane**

## สิ่งที่ตกลงไว้แล้ว

- แถบสถานะ: ตัด `ร่างกาย` (กลายเป็นเลือด + exhaustion) และ `ความรู้` (กลายเป็น INT + ความชำนาญ) เหลือ `จิตใจ` กับ `สายสัมพันธ์` เพราะ D&D ไม่มีสองอย่างนี้แต่เกมชีวิตต้องมี
- สายผจญภัย: มีการเผชิญหน้าสั้น ๆ เป็นลำดับการทอยที่มองเห็น ไม่ทำแผนที่หรือการเดินหมาก

## สถานะปัจจุบันของไฟล์

ชุดที่ 1 ใส่ไปแล้วที่บรรทัด 810–915 แต่**ยังไม่มีอะไรเรียกใช้** — เป็นโค้ดที่นอนอยู่เฉย ๆ ไม่ได้เปลี่ยนการเล่น:
`ASI` (โบนัสสเตตัสตามเผ่า 5e), `SKILLS` (18 อย่าง), `BGS` (10 background), `DEITIES` (12 องค์พร้อมแกน alignment และชื่อภพ), `mod()`, `profFor()`, `XP_LV`, `lvlFromXp()`, `alignTh()`, `EXH_TH`, `hpMaxFor()`, `check()`, `rollTh()`, `logRoll()`, `gainExh()`, `healExh()`, `damage()`, `shiftAlign()` และฟิลด์ใน `S` ตอนเกิด

## ชุดที่ 2 — เอากฎไปขับชีวิต

**เริ่มต้นตอนเกิด** (ใน `birth()` ~บรรทัด 935) ตั้ง `S.hpMax=hpMaxFor()`, `S.hp=S.hpMax`, `S.prof=profFor(0)`, และ `S.saveProf` สองค่าตามภูมิหลัง

**Background ตกผลึกตอนบรรลุนิติภาวะ** เพิ่ม `S.focusYears` นับใน `tick()` แล้วเขียน `bgPick()` เรียกตอน `S.age===S.race.mature` ตัดสินจากจุดเน้นที่ใช้ตอนเด็ก + ชนชั้น + แคว้น ให้ความชำนาญสองอย่างที่ติดตัวไปใช้ทอยตลอดชีวิต

**การเลือกเทพประจำตัว** เพิ่มใน `DECS` ที่ `at:'c'` เงื่อนไข `age >= mature*0.8` เสนอเทพสามองค์ที่เข้ากับแคว้นและฐานะ บวกตัวเลือก "ยังไม่เลือก" · ศรัทธาสะสมจากการบริจาค การคุ้มครองวิหาร และงานอดิเรกทางศาสนา และจางลงถ้าทิ้งไว้ · **ไม่บอกผลที่ตามมาตอนนั้น**

**ทอยป้องกันประจำปี — เครื่องยนต์หลัก** หนึ่งการทอยต่อปีจากตารางภัยถ่วงน้ำหนัก (CON โรคและความอดอยาก, DEX อุบัติเหตุ, WIS ความสิ้นหวัง, STR งานเกินกำลัง, CHA ถูกเอาเปรียบ, INT ถูกหลอกสัญญา) DC = `8 + round(region.danger*2) + round((age/span)*5)` · ไม่ผ่านเสียเลือด / exhaustion / ทอง / จิตใจ · ทอย 20 ได้ปีที่ดี ทอย 1 เจอเรื่องร้าย

**แปลงเหตุการณ์และการตัดสินใจเป็นการทอย** เพิ่มฟิลด์ `chk` ให้ `EVENTS` ราว 15 รายการที่เหมาะ ที่เหลือคงเป็นบรรยากาศ · ส่วน `applyChoice()` (~บรรทัด 1518) ตอนนี้ใช้ `Math.random()` ลอย ๆ อยู่หลายจุด เปลี่ยนเป็น `check()` ทั้งหมด: เข้าวิหาร→Religion, ลงสมัครสภาเมือง→Persuasion, สมัครสำนักเวท→Arcana, ขอญาติช่วยหนี้→Persuasion, รักษาที่บ้าน→Medicine

**XP และเลเวล** สายผจญภัยได้ XP ต่อปีตามจุดเน้น ใช้ `lvlFromXp()` แล้วคำนวณ `prof` กับ `hpMax` ใหม่เมื่อเลเวลขึ้น · คนธรรมดาอยู่เลเวล 0 เลือด 4 โบนัสความชำนาญ 0 ตลอดชีวิต ซึ่งคือ stat block "commoner" จริงใน 5e และคือข้อโต้แย้งของเกมที่พูดด้วยภาษากฎ

**ฟื้นเลือด** ปีที่ไม่โดนอะไรเลยฟื้นเต็ม (เทียบเท่า long rest) ปีที่โดนฟื้นครึ่งเดียว

**การเผชิญหน้าสั้น** เมื่อจุดเน้นเป็น `delve` หรือ `guard` รันลำดับสามการทอย (โจมตี vs AC → ความเสียหาย → ทอยป้องกันหนึ่งครั้ง) บันทึกเป็นก้อนเดียวในบันทึกชีวิต และให้ XP

## ชุดที่ 3 — ความตายและแผ่นตัวละคร

**เปลี่ยนความตายจากสุ่มเป็นเสียเลือด** `hazard()` (~บรรทัด 1354) เลิกเป็นโอกาสตาย กลายเป็นโอกาสเจอ "ภัยถึงชีวิต" ที่ทอย CON save แล้วสร้างความเสียหาย · ชราภาพ = ทอย CON save ทุกปีหลังเลยอายุขัย DC สูงขึ้นเรื่อย ๆ · บรรทัด 1435 เปลี่ยนจาก `die()` เป็นเช็ก `S.hp<=0` แล้วเข้า `dying()`

**`dying()`** คนในบ้านหรือนักบวชทอย Medicine DC 10 เพื่อพยุงไว้ · ถ้าไม่มีใครหรือไม่ผ่าน ทอย **death saving throw**: 10 ขึ้นไปสำเร็จ ต่ำกว่าล้มเหลว สามสำเร็จรอด สามล้มเหลวตาย ทอย 20 ฟื้นทันทีที่เลือด 1 ทอย 1 นับเป็นสองล้มเหลว · รอดแล้วได้เลือด 1 และ exhaustion +1

**การตัดสินที่ Fugue Plane** เมื่อตายจริง วิญญาณไปยืนต่อหน้าเคเลมวอร์ — มีศรัทธา ไปภพของเทพองค์นั้นโดยระบุชื่อภพ · **ไม่เคยนับถือองค์ไหน ถูกก่อเป็นกำแพงแห่งผู้ไร้ศรัทธา** · เคยนับถือแล้วทิ้ง โทษหนักกว่า · แล้วค่อยเสนอ Raise Dead ถ้าเงินถึง

**หน้าจอระหว่างเล่น** แผงซ้ายกลายเป็น character sheet: สเตตัสหกตัวพร้อมตัวปรับ, แถบเลือด, AC, โบนัสความชำนาญ, เลเวล/XP, background, ความชำนาญ, ตาราง alignment 3×3 พร้อมจุด, เทพและศรัทธา, จุด exhaustion · คงแถบ `จิตใจ` กับ `สายสัมพันธ์` ไว้สองอัน

**แผงลูกเต๋า** โชว์การทอยล่าสุดตลอดเวลา (`ทอยป้องกันทน DC 13 — d20 7 +2 = 9 · ไม่ผ่าน`) ส่วนบันทึกชีวิตบันทึกเฉพาะที่ควรจำ (ไม่ผ่าน / ทอย 20 / ทอย 1) เพื่อไม่ให้ท่วม

**หน้าจอตาย** กลายเป็นแผ่นตัวละครเต็มใบ + คำตัดสิน + หัวข้อ "ความสามารถที่ไม่เคยได้ใช้" (เช่น `STR 17 — ไม่เคยได้ทอยอะไรที่สำคัญเลยสักครั้ง`)

## เป้าหมายตัวเลข (ตั้งไว้ก่อนลงมือ)

ทั้งเซสชันนี้ผมพลาดเรื่องสมดุลซ้ำ ๆ เพราะไล่แก้โดยไม่ได้ตั้งเป้าก่อน รอบนี้ตั้งไว้ล่วงหน้า:

| ตัวชี้วัด | เป้า |
|---|---|
| อายุกลางของมนุษย์ | 62–68 ปี |
| จังหวะที่ต้องทอย death save | 1–2 ครั้งต่อชีวิต ไม่ใช่ทุกปี |
| ทอย death save แล้วตายจริง | 60–70% ของจังหวะนั้น |
| ตายโดยไม่เคยนับถือเทพองค์ไหน | 25–35% (ต้องมากพอให้กำแพงมีความหมาย) |
| คนธรรมดาจ่ายค่าชุบชีวิตไหว | 8–12% (คงเดิม) |
| อัตราได้เป็นนักผจญภัย | ~20% (คงเดิม) |
| การทอยที่มองเห็นต่อปี | อย่างน้อย 1 |

## การตรวจสอบ

1. `node --check` หลังทุกชุด
2. ตัวทดสอบ headless ตัวเดิมที่ใช้มาทั้งเซสชัน (stub DOM, แทน `openDec`/`reveal`, รัน 1,500–2,000 ชีวิต) รายงานตัวเลขตามตารางข้างบน
3. ตรวจ `check()` แยกต่างหาก: ทอย 100,000 ครั้งยืนยันว่า d20 กระจายเรียบ และ advantage/disadvantage ขยับค่าเฉลี่ยไปทางที่ถูก
4. รันตัวทดสอบภาพที่เขียนไว้แล้วซ้ำ ยืนยันว่า portrait กับฉากไม่พัง
5. เผยแพร่ต่อเมื่อตัวเลขเข้าเป้า

## ความเสี่ยง

- ตัวเลขเปลี่ยนทั้งระบบ คาดว่าต้องปรับสมดุล 2–3 รอบ
- คนธรรมดาเลือด 4 หน่วยเปราะมาก ขนาดความเสียหายต้องปรับให้ปีส่วนใหญ่รอด ไม่งั้นจะต้องทอย death save ทุกปีจนหมดความหมาย
- **เวอร์ชัน 6 ที่เผยแพร่อยู่จะไม่ถูกแตะจนกว่าตัวเลขจะเข้าเป้า** เกมที่เล่นได้อยู่ตอนนี้ยังอยู่ครบตลอดการรื้อ
